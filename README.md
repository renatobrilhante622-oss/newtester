# MU Reborn — Android

Projeto de RPG 3D mobile inspirado em MU Online, com modo offline inicial e arquitetura preparada para multiplayer futuro.

## Estado

Este repositório está em fase de fundação. **Ainda não contém cliente compilável nem APK.** A base candidata é [xulek/muonline](https://github.com/xulek/muonline), que deve ser auditada quanto a licença, dependências, arquivos de dados e suporte Android antes de incorporar código.

## Metas

1. Auditar e integrar legalmente a base MonoGame Android.
2. Compilar e executar no Android com assets redistribuíveis.
3. Separar renderização, simulação offline e persistência.
4. Implementar joystick, combate e farm automático.
5. Adicionar multiplayer autoritativo em etapa posterior.

Consulte `docs/ROADMAP.md` na branch de desenvolvimento.
